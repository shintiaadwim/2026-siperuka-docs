# 2026 PraPDBL Siperuka - Documentation

## Description
SIPERUKA is a campus room booking management system for 2026, designed to streamline booking, history tracking, and user management.

## Features
- CRUD modules for Booking, Room, and User
- Booking History and Booking Status management
- Validation and error handling
- Seed data for Room and Booking Status
- Integration with GitHub Project Board

## Tech Stack
Backend
- .NET 8 (ASP.NET Core Web API)
- Entity Framework Core 9
- OpenAPI/Swagger
Frontend
- React 19.2.4
- TypeScript
- Vite 7
- MUI (Material UI)
- React Router
Database
-SQL Server Management Studio

## Installation
Backend
- Open folder: Backend
- Restore dependencies: dotnet restore
- Update connection string in appsettings.json
- Run the API: dotnet run
Frontend
- Open folder: Frontend
- Install dependencies: npm install
- Start dev server: npm run dev
